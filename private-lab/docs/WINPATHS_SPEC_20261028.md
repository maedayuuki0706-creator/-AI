- 2026年開催情報は未接続につき現状は登録番号の手入力。将来の出走表自動取得は別機能。公式勝率（得点率）とは区別。

## 数値定義と分母
| 表示名 | 定義 |
| --- | --- |
| 1着率 | 対象選手が指定枠または指定実進入コースで1着となった回数 ÷ その位置での出走回数 |
| 2連対率・3連対率 | 同じ位置で2着以内・3着以内となった回数 ÷ 出走回数 |
| 逃げ率 | 対象選手自身の「逃げ」1着回数 ÷ その位置での出走回数 |
| 逃し率 | 相手1コースが「逃げ」で1着となった回数 ÷ 対象選手のその位置での出走回数（結果からの代理指標） |
| 2コース逃がし率 | 対象選手が**実進入2コース**で走ったとき、1コースが「逃げ」で勝利した回数 ÷ 2コース出走回数 |
| まくられ率（1枠/1コース） | 対象選手がその位置で**負けたレースのうち**1着艇の決まり手が「まくり」の回数 ÷ 敗戦回数 |
| 差され率（1枠/1コース） | 同様に相手1着艇の決まり手が「差し」または「まくり差し」の回数 ÷ 敗戦回数 |
| まくり・まくり差し・差し勝ち率 | 対象選手自身の指定決まり手1着回数 ÷ その位置での出走回数 |
| 決まり手構成比 | 対象選手がその位置で1着になったレースで、その決まり手が占める割合 ÷ 1着回数 |

**枠番と実進入の違いを混ぜない。** たとえば6号艇が4コースに入ったレースは、「6枠の成績」と「4コースの成績」それぞれの母数に含め、6コースの母数には入れない。

「まくられ率」「差され率」の相手決まり手は最終的な1着艇の公式決まり手を用いて判定している。航跡映像・1マーク経過を保有していないため、**具体的にどの艇が攻撃され、どの隊形が生じたかの直接観測ではない**。競技結果からの敗戦分類であり、確率予測や因果効果の推定とは異なる。

## 根拠・期間・注意事項
- 元DB: 公式K結果2022年1月1日〜2025年12月31日、205,269レース、1,231,614出走記録、6艇完全採用、選手1,794名。
- あくまで保存したレースが分母で、全開催を完全に網羅しているとみなさない。
- 標本数10未満は注意表示。平均比の注目点は標本20走以上、該当決まり手勝ち2件以上、差3ポイント以上でのみ暫定表示。
- 予測精度・期待値・回収率を裏付けるバックテストは未実施。
- 今回の集計はレース後の結果であり、2026年の出走表・展示・オッズ・今節平均STを入力した研究エンジンではない。
