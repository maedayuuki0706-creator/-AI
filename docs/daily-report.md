# 配信と日次集計

2026年9月13日は開催中の全場・全レースを配信対象とする。展示・オッズが未公開の予想は暫定と表示し、締切前の自動実行で再判定する。公式データの欠損や実行遅延で締切に間に合わないレースを、事後予想で埋めない。

Discordでは本線・押さえ・穴のフォーメーション、重複除外した点数を表示する。仮想投票は1口100円。既存の配分器の上限は1レース30口で、実際の購入は行わない。配分対象の買い目・口数を送信ログに保存する。

各レースの集計対象は締切前の最新配信1件。朝予想から直前予想への更新は差替えとして扱い、両方の投票額を足さない。配分記録がない過去の予想に投票額を後付けしない。

回収額は、公式3連単払戻金（100円当たり）×買い目の口数に返還金を加えた額。表示時点のオッズは清算に使わない。未確認結果は保留し、確定した投票額だけを回収率の分母にする。予想全点の的中率と、実際に仮想配分した買い目の的中率を分ける。全返還と特払いは的中率の分母から除外する。

日次報告は23:30 JST予定。公式結果の遅れには23:50と翌00:30の再確認で対応する。GitHub Actionsの実行時刻には遅延があり得る。同じ内容の報告は再送せず、更新があった部分を送る。通知機能の更新時には、その時点の暫定まとめも送る。

`data/daily_reports/YYYYMMDD.json` と `.md` に全体・場別・レース別の集計を保存し、`data/official_results/` に公式清算データ、`data/report_deliveries.jsonl` に報告の送信記録を残す。ローカル確認は `python daily_report.py --day YYYYMMDD`。`--send` を付けた場合のみDiscordへ送信する。
