## 原因と対処

旧研究は5分 cron の設定があっても、実際の実行は数時間間隔だった。2026-10-12 の記録は取得が55秒で時間切れになり、予想の保存が0件。

専用ブランチへの push で研究を開始し、研究ワークフローだけを約4分周期で継続する。所有者が無効化したワークフローは再有効化しない。稼働中のジョブは停止・再起動しない。曖昧な dispatch 応答は再試行しない。

cron は default branch の main にしか作用しないため、専用ブランチの継続は夜間も維持する。夜間は collector の時刻ガードで新しい予想を生成せず、翌朝の実行につなぐ。

展示が未公開なら、その欠損を記録して取得を待つ。展示6艇が揃ったら、出走表・オッズ・締切表・日和を並列取得する。研究の取得予算は125秒、各取得プロセスは最大90秒。締切3分前を過ぎた生成は拒否し、remote push 後の保存確認時刻が締切前のものだけを採点・シート投影する。
