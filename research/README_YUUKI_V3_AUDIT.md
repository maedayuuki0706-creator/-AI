# ゆうきV3 先読み展開監査（研究・配信完全分離）

## ここまで実施したこと

- 既存 `research-fusion-shadow-state` の事前固定予想を**読むだけ**
- 公式の事後検証が保存され、**予想とGit保存の両方が締切前**と確認できるレースに限定
- 予想ダイジェストの不一致・未確定・返還・期限後保存・6艇根拠不足を除外
- 同額の10点買い目を `fusion / existing / hiyori / sheet_db / knowledge_v2` で比較
- 不的中を「当たり頭の買い目なし」「頭は拾ったが組み合わせ違い」に分類
- モデル最高評価の頭が実際に1着だったかを**買い目の頭カバーとは別**に計測
- 決まり手の一致はあくまで**幅広い仮説との整合性**で、進入や攻めの因果を証明しない

## 運用制限

- GitHub権限は `contents: read` のみ
- 本番の `main` は変更しない、別ブランチでコードとテストを保持
- 研究ワークフローはこのブランチへのpushでのみ起動。**定期起動は未設定**
- Discord、X、Render、Google Sheets、Webhook、Secrets、既存配信の設定には**一切触れない**
- 公式検証が未完了のレースは不的中として数えず「保留」
- 実力比較は**期間外検証・確率較正・同一情報時点**がそろってから
