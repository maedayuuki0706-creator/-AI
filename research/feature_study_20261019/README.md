# 2026-10-19 予想特徴量研究（本番非接続）

目的：新ゆうき・江戸川/児島/唐津/浜名湖専門AIに対し、予測時点の情報だけを使う追加特徴量を独立検証する。ここに書く外部記事の数値は未再現であり、固定係数として採用しない。

## 検証する特徴量
1. 風速・風向・波高：場別、季節別に記録。風速条件付きで波高の追加寄与をアブレーション比較し、二重評価を防ぐ。
2. 展示タイム・一周/まわり足/直線タイム：場・節・測定条件で標準化し、1着と2/3着の双方の確率を検証。欠損は欠損として扱う。
3. 展示進入と本番進入：予測時には本番進入を参照しない。展示進入からの変更確率を推定し、進入シナリオ別に展開を評価。
4. 地元支部・当地経験：級別、選手能力、コース、開催グレード、場を統制して増分効果を測定。地元優位を定数加点しない。
5. トリガミ・EV：締切前の取得時刻付きオッズと確定オッズを別保存。均等購入時の買い目別払戻、トリガミ確率、合成オッズ、期待回収額を算出。トリガミも実際のROI集計に必ず含める。

## 展開と2・3着
全6艇について勝ち筋/負け筋（事故除外）を仮説として事前保存。攻めの起点、差し/まくり/まくり差し、内の抵抗、外の連動を分岐させ、P(1着艇,決まり手,2着艇,3着艇)を一貫した同時分布として評価。決まり手は結果判明後に予測特徴量へ混入させない。

## 実験設計
- 同じレース・同じ取得締切時点で既存モデル、単独特徴量追加、全追加を比較。
- 時系列分割、場別・風速帯別・人気帯別の件数と信頼区間を併記。
- 指標：log-loss、Brier、確率校正、3連単的中率、全買い目込みROI、トリガミ率、欠損率。
- 事前予想原本と結果レビューを別保存し、データリークを検査。
- 十分なサンプルとアウトオブサンプル改善が確認できるまで研究限定。
