# 研究材料を6艇の判断に使う

取得した選手のコース別履歴を、既存 `prediction_engine.analyze_race` の入力へ渡す。唐津の直線・回り足・一周の実測は、既存 `scenario_v2` の攻め成立条件、後続艇の反応、2着・3着候補へ渡す。保存件数の報告で終わらず、**どの入力を使い、どの買い目が入れ替わったか**をレース別に残す研究専用アダプター。

本番、既存worker、既存研究原本、Discord、X、Sheets、Secrets、既存ワークフローは変更しない。ネット取得・定期起動・配信・投票の処理はない。このPRは独立した研究コードと、実データを使った出力例を追加する。

## 接続したもの

|材料|使う場所|使い方|
|---|---|---|
|選手×実コースの出走・1着・2/3連対数|既存メインのコース評価、後続候補|`racer_profiles` と同じ12走分の事前値・3走以上の基準で平滑化。元の公式値があれば上書きしない|
|選手×実コースのSTと決まり手|既存メインのST・攻め型評価|既存の標本数による縮小を再利用。当該レースの本番STは参照しない|
|唐津の直線・回り足・一周|新ゆうきの分岐と後続艇|同一レース6艇内の順位。直線上位なら握る攻めの条件、回り足上位なら差し・まくり差しの条件と後続選抜に使う|
|モーター履歴|各艇の説明欄|場・周期・機番を分ける。現周期の継続が未照合なら数値加点はしない。公式2連率との二重加点も行わない|
|風・波など|公式coreの既存入力、レースの観測条件|公式の展示時原本を維持。結果時の風に置き換えない|

潮位とコメントをスコアへ渡す処理は、この第一弾には含めない。潮位の場内対応とコメントの時点・意味を別途確認する。未接続項目を接続済みと表示しない。

## 比較条件

同じレースで各10点・1点100円、次の5種類を保存する。

1. 公式出走表・展示のみのmain core。
2. コース事前値だけを補った対照群。
3. 取得した選手コース履歴を補ったmain core。
4. 3＋新ゆうき（独自展示なし）。
5. 3＋新ゆうき＋独自展示。

2を置くことで、元coreの空欄がコース事前値で埋まった効果と、実際の選手履歴の効果を分ける。4と5の差では、履歴と平均STを固定したまま独自展示が何を変えたかを確認できる。新しい係数を今回の結果に合わせて学習・調整していない。

## 原本と時刻

- 入力は既存の締切前公式原本から再構築し、6艇の登録番号・機番・進入・展示タイム・ページのSHA256を既存アダプターで照合する。
- 独自展示は同じレースの公式URL、日付、6選手名、枠別展示タイム、原文ハッシュを照合してから使用する。
- 選手履歴は対象レースより前の日だけを使う。集計期間末が対象日以降なら、その集計を流用せず、過去日までの履歴から再集計する。再集計できない決まり手は欠測にする。
- 旧資料の `predictive_input_allowed=false` は上書きしない。新しい研究モデルへ取得後に読み込んだ事実を `materials_loaded_at` として記録する。過去レースでは常に事後研究。
- `live` は当日の締切3分以上前に限る。生成後にロードした材料・未来の取得時刻・締切後に取得した独自展示を使わない。ローカル生成だけでは前向き成績に数えない。
- `replay` は現在の生成時刻と元公式原本の取得時刻を別に保存する。独自展示が締切後取得ならその事実を残す。締切前に利用できたと表示しない。
- 原本を変更せず、JSON・Markdownは既存ファイルを上書きしない。生成処理は結果ファイルを読み取らない。

## 実行

取得済み「競艇AI_研究材料_追加収集結果_20261020.zip」の `data/` と、既存の専用stateを読み取り用に使う。原本を再取得する必要はない。

```sh
python -m unittest research.materials_application_v1.test_application -v
python -m research.materials_application_v1 \
  --materials /path/to/acquired/data \
  --state /path/to/materials-state \
  --inputs /path/to/materials-state/reused_inputs \
  --out /path/to/new-output \
  --day 20261020 --mode replay
```

予想を固定してから、独立したレビューを実行する。

```sh
python -m research.materials_application_v1.review \
  --forecasts /path/to/new-output \
  --results /path/to/materials-state/results \
  --out /path/to/new-review.json
```

レビューは事故・返還を除外し、頭・2着・3着の選択漏れと展示→本番の進入変化を記録する。全6艇の実際の攻防を映像確認したことにはしない。

## 次の運用接続

このPRのアダプターは、研究用の新しい締切前入力から `build(snapshot, materials, state_root=..., mode="live")` を呼べる。ただし既存の定期workerはPR #49のSHAに固定されており、**このPRは既存workerの実行コードを変更せず、自動運転への接続も行っていない**。将来レースでの遠隔保存・独立採点は次の運用接続として残る。実際の取得と100R→300Rの比較で、履歴や足を使う方式の改善・悪化を評価する。
