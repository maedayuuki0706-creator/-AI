# 航跡 — BOAT LAB｜6艇実データ比較研究・第1段階

既存の配信・サイトを触らず、過去レース記録から**6艇の実進入コース別実績**を集計して、読みやすい比較表を出す独立した研究版です。Cloudflare Workerは削除された状態のままで、**再デプロイしません**。

## 使い方（開発環境）

```bash
python -m unittest discover -s research/kouseki_study_v1 -p 'test_analytics.py' -v
python research/kouseki_study_v1/build_bundle.py \
  --archive data/exhibition_log \
  --target data/exhibition_log/20261103/01_10.json \
  --out research/kouseki_study_v1/dist/
```

`dist/index.html` を開けば、同じディレクトリの `report.js` に格納された実績データを読み込めます。別のレースの集計JSONも、画面の「分析データJSONを読み込む」から読めます。GitHub Actionsの研究用ジョブでも同じ出力をビルドし、ダウンロード可能なアーティファクトにします。

## すでに実装した内容

- 24場に対応した場・レース選択UI、6艇同時表示、左側固定列、iPhoneの横スクロール
- 実**進入コース**別の過去10走（全国）、過去1年（収録分）、当地×コース過去1年（収録分）
- 1着率、2着率、3着率、3連対率、平均本番ST、ST標準偏差、ST.15以下比率、素点平均
- 同じ場・実進入コースの収録データによる場平均、n、95% Wilson区間（内部JSON）
- 対象日**より前の日付**の確定結果だけを研究に使用。対象レースの着順や当日の確定結果は入力に混入しない
- AI推定3連対確率は**未校正につき未表示**（`null`）。根拠が薄い統計シグナルは無理に出さない
- 収録日付範囲、観測日数、標本数、欠測・未収録の警告を表示
- JSON持込み方式：ブラウザからGitHub・Cloudflareへのログイン不要、秘密鍵不要

## データの正確性と制限

- 元データは `data/exhibition_log/YYYYMMDD/CC_RR.json`。`settled: true`、6艇ID、実進入、1〜6着が確定したデータを集計します。
- **「過去1年」＝1年前から対象日前日までの収録済みレコード**。過去1年が全部揃ったという意味ではありません。現在のソースは約1か月程度で、取得がない日に注意が必要です。
- 直近10走は**各選手×実進入コースの直近10走**。他コースの直近10走から間引かない。
- F・失格・欠場等の記号着順は分母から除外。将来、公式扱いに合わせるため欠場や事故の区分を拡張予定。
- 着順点は `10/8/6/4/2/1` の**素点平均**。SG・G1/G2・優勝戦の点増し情報がないため、「公式勝率」と同一視しない。
- 「過去1年の勝率」を完全表示する前に、長期データ収集と競走格付け・事故の正規化が必要。
- 展示・モーター・風・潮、独自AIの予測確率は**未接続**。見せかけの数値は生成しません。
- 条件探索の研究メモは未検証の記述統計です。未来レースで再現したと確認するまで勝ち筋の断定をしません。
