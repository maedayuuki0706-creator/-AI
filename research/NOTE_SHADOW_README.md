# note-inspired 確率補正・期待値研究 (Shadow v1)

## 安全境界
- **既存のDiscord / X / 本番PT1・PT2・ゆうき配信を一切変更しない。**
- 実投票なし。APIトークン・シート編集・外部通信は一切不要。
- GitHub本番ブランチへの変更なし。専用研究ブランチで開発・検証する。
- 本バージョンは **過去ログの時系列再生 (offline_replay)**。未来の自動取得・日次スケジュールは未設定で、**稼働中のライブ並行テストとは呼ばない**。
- 既存の `all-ai-fusion-shadow` は別システム。そちらの現状0件の有効予想やタイムアウトは、本研究の実績に混ぜない。

## データ元
- `data/prototype12_delivery/predictions/*.json`: PT1・PT2の実際の3連単120通りの事前確率と事前オッズ
- `data/prototype3_delivery/predictions/*.json`: ゆうきの事前確率と事前オッズ
- 対応する `deliveries` の**予想digestと一致する締切前の配信レシート**
- `data/prototype_scoreboard/YYYYMMDD/official/*.json`: 公式結果と100円当たり払戻

すべて、予想時刻 `<=` 配信確認時刻 `<` 締切のレースのみを採用。返還・特払い・同着などの曖昧な結果は除外し、原因を別カウントする。公式結果は予測には使わず採点と**以前の日付の学習**にのみ使う。

## 比較方法
- `native_logged`: 元の予想 (予想家の点数に依存)
- `raw_prob_10`: 補正前確率上位10点、各100円
- `raw_ev_10`: 補正前 `予測確率×事前オッズ` 上位10点、各100円
- `cal_prob_10`: 補正後確率上位10点 (単調補正なので原則 `raw_prob_10` と同じ)
- `cal_ev_10`: 補正後 `予測確率×事前オッズ` 上位10点、各100円
- `raw_ev_gate_85`, `cal_ev_gate_85`: EVを0.85倍と保守的に評価して、1を超える舟券だけ最大10点 (予算可変、別比較群)

補正指数は過去30日で最低100モデル別・バージョン別レースを学習する。閾値未達は指数1.0 (未補正) で明記。同じ日付の結果を同じ日の予想に混ぜない。モデル改変と旧/新PT2は同列に学習させない。

## 実行
```bash
python -m unittest discover -s tests -p 'test_note_shadow.py' -v
python research/note_shadow.py --repo . --out /tmp/note-shadow-results
```

出力: `summary.json` / `results.json`。いずれも指定した別ディレクトリ。**元の `data/` は読み取りのみ**。

## 検証・導入の順序
1. 再生で受付レシート・120通り・評価額に欠陥がないか調べる。
2. 連続した新しい期間の評価でEV選択と補正の追加価値を確認。
3. 既存fusionシャドーの予想生成タイムアウトを解消し、事前固定の有効サンプルを確保する。
4. 全AI融合の研究ログに同じ出力形式を追加。ライブ化する際は新規の独立したjobとstate branchで運用。**本番配信ワークフロー・Render本番サービスには接続しない。**

現時点では GitHub Actions 定期実行、シート書き込み、Render追加課金、Discord/X配信は有効化していない。

## 解釈上の注意
過去ログの再生は、今後のライブ的中率・回収率を保証しない。オッズは投票締切時と異なるため、事前オッズと確定オッズの差を保存し、実現可能性の補正が必要。分位点回帰・STモンテカルロ・SHAP・ホースケリーは後続研究として別バージョン管理する。
