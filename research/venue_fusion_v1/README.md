# 4場専門AIの研究ベース｜既存メイン君 ＋ 新ゆうきv2 ＋ 場別

**研究専用。既存メイン・場別研究ワーカー・Discord・X・Render・Sheets・予想配信は一切変更しません。**

## 三層の役割

1. **既存メイン君が土台**：本物の既存 prediction_engine.analyze_race() を変更せずに直接使用。選手・コース・平均ST・モーター・展示・当地・進入等から120通りの順位を作る。過去の的中確率を保証するものではない。
2. **新ゆうきv2が展開の脳**：本物の research.scenario_v2.engine.generate() で6艇全頭の勝ち筋・負け筋・攻めの起点・2着3着連動を分析。メイン上位6点は保持し、残り4点を事前条件に沿う展開候補から検討。
3. **場別くんが水面の専門家**：現行 research.venue_specialists_v1.engine.analyze() で7項目を判定。ただし場別の未検証係数は0。期間外検証に合格した条件だけを加点する。

## 認められる入力の条件

場別専門AIの現状の締切前LOGは、平均ST・モーター2連率・展示タイム等は持っているが、メイン君が使う全国/当地成績やボート成績などが不足。足りないデータを勝手に0.5へ補完すると、メイン君と同じ予想とは言えない。

そのため、次の全部が揃わなければ生成を拒否する：

- 同じ開催日・場・R・公式締切時刻
- 6艇の枠・登録番号・展示時点の進入コースの完全一致
- 別収集した公式時刻が未来でないこと、収集差は最大120秒
- 必須選手/モーター/当地/ボート情報が全艇で存在すること
- 取得元のハッシュ・時刻と、過去DB/プロフィール・前日フォームの当日時点の確認
- レース結果・本番ST・本番の実進入・決まり手・配当は入力禁止

研究用 API の production_preprocessing_verified フラグは**入力を実際に監査した側しか立ててはいけない**。フラグを置いたこと自体は証明にならない。
