# BOATERS型データ拡張 Phase 3 — 過去レース数十万件・選手別枠番/コース統計（2026-10-25）

## 要点と公式一次資料

- 公式： https://www.boatrace.jp/owpc/pc/extra/data/download.html
  - 全国24場の「競走成績ダウンロード」および「番組表ダウンロード」の入口がある。
  - 2002〜2026年のレーサー期別成績（前期/後期、LZH形式）も提供される。
- 公式レイアウト： https://www.boatrace.jp/owpc/pc/extra/data/layout.html
  - 登番/勝率/2連率/全国出走数、**各コース進入回数、1〜6着回数、F・L等の失格内訳、平均ST** を含む。
  - 期別成績の「コース」は**本番の進入位置**であって出走表の枠番ではない。進入が変われば別の値となる。
  - 古い時期はレイアウト改定の可能性があるため、2002年〜各年一律の固定バイト位置だと決めつけない。
- 参考： https://www.boatrace.jp/owsp/sp/extra/about.html の全国・当地の集計期間定義を確認する。
- 参考サンプル： https://boatman-a.com/lab/stats は2023-10-01〜2026-09-30を165,792レースと発表。これを自分たちの実収録数とは表記しない。
- 第三者CSV https://boatracecsv.github.io/docs/data/ も検証候補だが、一次資料との全件一致と利用許諾を確認するまで正本や公開再配布に使わない。

## 最優先1：選手期別成績の全期間取込

1. まず**直近1期だけ**研究領域へ安全に取得・解凍し、文字コード、バイト数、行数、年度別仕様を検証。ダウンロード頻度は配信元の条件内で抑制。
2. 1行ごとの登録番号、集計開始・終了年月日、全国勝率、全国出走数、コース1〜6の進入数、着順別1〜6回数、F/L/K/S、コース平均STを原本由来のまま保存。
3. **コース別1着回数・2着回数・3着回数・2連対率・3連対率・進入回数**を導出。
   - 1着率＝1着回数 / 分母
   - 2連対率＝(1着回数＋2着回数) / 分母
   - 3連対率＝(1着回数＋2着回数＋3着回数) / 分母
   - 分母は公式の「進入回数」か、失格等を除いた「有効出走回数」かを**公式指標の値と照合して固定**。0回は「算出不能」として null。
   - 公開時には必ず「1着/2着/3着の実数、分母、集計期間、進入コース」をセットで表示する。
4. 公式に公表されたコース複勝率/全国複勝率と100名以上のサンプルで照合。合わない場合、分母定義・特殊競走扱いを検討し、無断で値を補正しない。
5. 1期ずつ検証してから複数期へ展開。期間重複、同一選手の登録番号変更・引退、途中期の欠測を検出。重複した期間を単純合算しない。
6. 実取得済みのレコード・重複・欠測を監査する。出所と期を原本保存領域へ（GitHubの公開viewerへ元データを大量コミットしない）。

## 最優先2：日次競走成績＋番組表の大規模取込

1. 公式競走成績/番組表のうち、直近30日を最初に収集して試験、その後1年→3年→5年へ増加。過去データ取得が可能な範囲は実際のリンクとアクセス結果で確認する。
2. 競走成績だけでは**登録番号と枠番別勝数**は断定できない。必ず番組表と照合し、日付+場コード+R+艇番で結合。
3. 長期DBは `race_id=(YYYYMMDD,jcd,rno)`、`entry=(race_id,boat_number,racer_id)`、`result=(race_id,boat_number,course,rank,st,kimarite)` を独立保存する。
4. **枠番（出走表の号艇）** と **本番進入コース** は絶対に混ぜない。欠測は null/unknown。進入変更があれば両方記録。
5. 枠別1着/2着/3着件数、1/2/3連率、コース別の同指標、当地24場別、30/90/180/365日、直近5節・直近10走、決まり手別成功数、ST平均を登録番号・期間で集計。
6. 欠場/返還/F/L/失格/中止/同着の扱いを分ける。**分子・分母・除外数・出所・収録範囲**をセットで保存。
7. 参考目安：全24場で年間約55,000R規模。過去5年で約275,000R・6艇分約1,650,000出走行になり得るが、**現時点で取得済みと主張しない**。

## 推奨データ設計

- `raw_sources`: URL、配布元、取得日時、対象日/期、ハッシュ、サイズ、取得可否、利用条件
- `races`: 日付、場、R、グレード、天候・風・水面、決まり手、払戻、成立/中止
- `entries`: race_id、登録番号、号艇、級別、モーター番号、事前全国/当地勝率
- `results`: race_id、登録番号、号艇、本番コース、着順、ST、失格、決まり手
- `player_course_period_stats`: 登録番号、対象期間、場（全国または当地）、軸（枠番/コース）、番号、着順1〜6件数、除外、分母、1/2/3連率、平均ST
- `data_quality`: 原本数、正規化成功・失敗、重複、異常、母数、鮮度
- 保存は研究用SQLite/DuckDB等に分離。公開するのは利用条件の許諾が得られた範囲の軽量な**派生集計値のみ**。全履歴JSONをブラウザに読み込ませない。

## サイトの画面計画

- 選手検索：登録番号/氏名/級別/支部で検索、全国vs当地、進入コースvs枠番の切替、対象期間選択
- 枠/コース1〜6の行に、進入/出走数、1着/2着/3着件数、1着率、2連対率、3連対率、平均ST、決まり手の件数/率を表示
- 例：「3コース 20走｜1着4回｜2着5回｜3着3回｜1着率20.0%｜2連対率45.0%｜3連対率60.0%」（**架空の表示例**）
- 研究条件：江戸川/児島/唐津/浜名湖 × 風向風速/潮位/進入変更/級別/直近開催。少数標本は警告。
- 出走表は当該日以前に確定した成績スナップショットしか予想入力に使用しない。現時点のランキングデータを過去の予想再現に混入させない。
