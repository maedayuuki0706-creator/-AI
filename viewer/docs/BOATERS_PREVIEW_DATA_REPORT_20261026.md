## 取得できた項目と安全性

- `previews/stt`：展示進入コース、展示ST（**本番STではない**）。
- `previews/tkz`：展示タイム、チルト、体重、調整重量。
- `previews/sui`：風速、風向、波の高さ、気温、水温、天候。
- `previews/od3`：3連単全120通りの「取得された時点」のオッズ。最終オッズではない。
- `previews/original_exhibition`：一周、まわり足など場・日付依存の計測項目。値1/2/3の意味は日別ヘッダの情報を失わず対応する必要がある。現スキーマには数値だけ保存しておりラベルは未保存、指標間比較への直接使用禁止。
- `programs/motor_stats`：モーターの日別時点集計。掲載の日付が締切前だった保証がないため、データリーク検証まで事前モデルへ入力禁止。
- `programs/motor_history`：ソース行数の監査のみ、個別の履歴行はSQLiteへ未保存。誤って「取得/保存済み」と宣言しないこと。

## 次の研究実装（勝率・回収率向け）
1. 公式B/Kの同期間結果とレースコード・枠番・実進入を照合し、差異と未結合を分離。
2. 3連単 `odds3` と**締切前**の予想原本・買い目を結合。レース終了後の結果はスコアリングにのみ使用し、未来情報の混入を禁止。
3. 3連単全120通りの指数と期待値・高配当のサンプル母数/トリガミ/回収率を分けて検証。
4. 江戸川・児島・唐津・浜名湖の専門研究で場別に偏ったサンプルを区別し、風向×風速×波高×進入×モーター周期の標本を確保。
5. 気象庁の毎時潮位（JST、観測基準面cm、観測地点の移転・基準面変更あり）を観測所別に収集・品質管理する研究設計。https://www.data.jma.go.jp/kaiyou/db/tide/sea_lev_var/format_download.html
6. 取得日次の欠測、ファイル404、更新時刻、原本の権利条件を監査してからUIへ統合する。
