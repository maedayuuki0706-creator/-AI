# PT2 & 出走表 閲覧専用ビュー

このフォルダは、既存の競艇AI本番システムと独立した**公開静的サイト**です。

## 仕組み
- 競艇場、日付、R番号の選択はブラウザ内だけの状態。GoogleスプレッドシートのB2/C2/A3は更新しません。
- **PT2予想**: 公開GitHubの `data/prototype12_delivery/predictions/YYYYMMDD_JCD_RR.json` に書き出された保存済みモデル結果を閲覧します。現行の `strategy_cards.cards` から総合型・本命型・妙味型・高配当型を表示します。『激絞り』などSheet側の独自組み立て表示は含みません。
- **出走表**: 独立サービス `boat-sheet-feed.onrender.com` の読み取り専用CSV `venues.csv` / `race.csv` / `race_roster.csv` を参照。場とRごとに読みます。
- **選手検索**: `選手データ`シートの1660名の表示用スナップショットを検索時に読み込みます。名前の部分一致、空白を無視したフルネーム、全角/半角登録番号に対応。1〜6コース1着率、決まり手、平均ST、評価・コメントを表示します。空欄と0を区別します。
- 選手情報の更新は既存の `main/data/sheet_db/meta.json` を先に確認し、新しい場合のみ既存 `players.json` を取得します。Sheets認証や書き込み、予想生成、配信処理は呼び出しません。
- **高速表示**: `build_data.py`は取得済み予想・日和の公式出走入力から直近7日分の最小JSONを作ります。約92KBの予想は、6艇の出走情報を含め約2.4KBになります。新しいレースは既存mainブランチの公開データにフォールバックし、表示対象レースを検証します。
- 出走表は保存時点のデータを先に表示します。保存がない場合や「情報を更新」を押した場合は既存公式フィードを取得します。無料フィードの休止による待ち時間が出ることはあります。
- PT2更新は小さい既存配送記録のdigestを確認してから必要時だけ完全な予想JSONを取得します。強制更新時は直接取得します。表示・再取得は元の配信に干渉しません。
- CSS/JSを独立ファイルに分け、HTTPキャッシュと最大75件のレース用localStorageを使用します。選手データは検索時のみ取得し、次回表示はブラウザ保存データから開始します。
- 予想ソースには更新遅延があります。配信・スプレッドシートの現在値と常に完全同期しているとは限りません。見つからなければ空欄表示で、別レースを流用しません。
- GitHub rawのアクセスができないネットワークでは予想を表示できません。公式やソースへのリンクを案内します。
- このサイトは認証機能がありません。**公開されているデータだけ**が対象です。秘密キー、Webhook、個人データ、内部管理APIにアクセスしません。

## 公開方法
- Render Static Site / Root `viewer/` / Build Command `echo static-ready` / Publish `viewer`
- 専用featureブランチで新規サイトを作成すること。既存の `main` や `sheet-auto-update` のRender配信サービス設定を変更しないこと。
- アクセス権が必要になった場合は、別途認証付きのバックエンド設計に切り替える。
- 表示用データの再構築: リポジトリ直下で `python viewer/build_data.py`。出力の `viewer/data/races` と `manifest.json` をviewer専用ブランチに含めます。既存の配信・取得ブランチは変更しません。

## 動作確認
- 日本時間の現在日が既定になること
- 日付・開催場・Rを切り替えても元シートは変わらないこと
- 存在しないPT2 JSONが404の場合、別レースを表示せず案内すること
- 出走表が欠損していてもエラーの内容を示すこと
- スマホ幅で4つの戦略カードが縦並びになること
